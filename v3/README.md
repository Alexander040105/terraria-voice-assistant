# Terraria Voice Assistant v3

Offline, low-CPU, fully local voice assistant for Terraria.

## Stack

- **Frontend:** React + Vite + JavaScript
- **Desktop shell:** Electron
- **Backend:** FastAPI + WebSocket
- **STT:** faster-whisper
- **VAD:** Silero VAD (ONNX)
- **Embeddings:** nomic-embed-text-v1.5 via llama-cpp-python
- **LLM:** Qwen2.5-1.5B-Instruct via llama-cpp-python
- **Vector store:** sqlite-vec
- **TTS:** Piper (ONNX)

## Setup

1. Create a Python venv:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

2. Download the local models (~2 GB):
   ```powershell
   python -m scripts.download_models
   ```

3. Build the knowledge base from the v1 scraped wiki:
   ```powershell
   python -m build_scripts.scrape_and_embed
   ```

## Running in development

Start the backend and the frontend dev server separately:

```powershell
. .\.venv\Scripts\Activate.ps1
python -m uvicorn backend.main:app --port 8000
cd frontend
npm install
npm run dev
```

Then open `http://localhost:5173` in a browser.

## Headless mode

Run without the GUI using a microphone:

```powershell
python -m scripts.run_headless
```

## Desktop app

Run the Electron shell in development:

```powershell
npm install                # install Electron + electron-builder in the v3 root
cd frontend && npm install && npm run build
cd ..
npm start
```

The Electron window loads the built frontend and spawns the Python backend automatically.

## Tests

Install dev dependencies and run the test suite:

```powershell
pip install -r requirements-dev.txt
python -m pytest tests/test_pipeline.py
```

Run only the fast unit checks:

```powershell
python -m pytest tests/test_pipeline.py -m "not slow"
```

## Packaging

Build the frontend, bundle the Python backend, and produce an installer in `v3/dist/`:

```powershell
pip install -r requirements-build.txt
npm run dist
```

This produces:

- `build_scripts/dist/assistant-backend/` — PyInstaller one-dir backend
- `dist/Terraria Voice Assistant Setup.exe` — NSIS installer

## Architecture

```
Mic/Audio → Web Audio PCM (16 kHz) → WebSocket → VAD → STT → Retriever → LLM → TTS → WAV → WebSocket
```

The voice pipeline is driven by `backend/audio/vad.py` using the Silero VAD v5 ONNX model. The backend returns JSON updates for the transcript and answer, then a binary WAV message for the spoken reply.

## Notes

- The first launch downloads models on demand if they are missing.
- `backend/data/terraria.db` is generated by `build_scripts.scrape_and_embed` and can be rebuilt with `--rebuild`.
- Add `--limit N` to `scrape_and_embed` to build a small test database quickly.
